# Project rules

- Keep the quiz self-contained in `index.html`; do not add a server, build step, or dependencies.
- Preserve the quiz's 10-question flow, scoring, feedback, and restart behavior.
- Keep both light and dark themes working and respect reduced-motion preferences.
- Make controls keyboard-operable, visibly focusable, and clearly labeled for assistive technology.
- Prefer small, focused edits and verify changes in the integrated browser.
